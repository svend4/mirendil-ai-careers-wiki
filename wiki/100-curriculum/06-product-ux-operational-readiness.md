# Модуль 06: Product, UX и operational readiness

## Цель

Понять, как превратить AI R&D capabilities в продуктовый workflow с trust, review, metrics, readiness и понятной ответственностью.

## Изучить

- [Design Engineer](../20-positions/03-design-engineer/README.md)
- [Product Development](../20-positions/14-product-development/README.md)

- [Scorecard: Product and AI-native UX](../65-scorecards/05-product-ux-scorecard.md)

## Практика

1. Описать journey: hypothesis -> run -> eval -> review -> decision.
2. Спроектировать UI state model для agent proposal review.
3. Создать product metric tree: time-to-insight, review burden, trust, adoption.
4. Провести production readiness review для одного scenario.

## Артефакты

- Journey map.
- UI state matrix.
- Trace viewer requirements.
- Product metric tree.
- Readiness checklist.

## Проверка

- UI показывает evidence, uncertainty и risk flags.
- Пользователь может принять, отклонить или отправить agent proposal на итерацию.
- Product metrics измеряют результативность, а не только активность.

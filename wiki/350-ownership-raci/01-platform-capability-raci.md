# Platform capability RACI

## Ownership scope

Experiment object, artifacts, workflow states, API contracts and platform integrations

## RACI

| Type | Owner |
| --- | --- |
| Accountable | Platform owner |
| Responsible | Platform engineers, Agent Harness, Product Development |
| Consulted | Model Evaluation, Security, Infrastructure, Design Engineer |
| Informed | Research leads, onboarding owners |

## Escalation path

Escalate unresolved contract conflicts to weekly platform/research review.

## Required evidence

- Experiment contract
- Platform integration slice
- Handoff contract
- Decision record

## Review cadence

Use the relevant review from [operational review cadences](../310-operational-review-cadences/README.md). If a decision changes ownership boundaries, create a [decision record](../200-protocols-contracts/06-decision-record-schema.md).

## Acceptance checklist

- Accountable owner is one person or one explicitly named function.
- Responsible owners can produce the required evidence.
- Consulted roles are consulted before the decision, not after incident.
- Informed roles receive decision outcome and follow-ups.
- Escalation path is clear before urgency appears.

# Проверка кодировки

## Назначение

Вики написана на русском языке, поэтому повреждение UTF-8 сразу делает документацию непригодной. Проверка кодировки ловит две категории ошибок: недекодируемые UTF-8 файлы и типичный mojibake после неверного чтения кириллицы.

## Команда

```powershell
.\tools\check-wiki-encoding.ps1
```

По умолчанию проверяются Markdown и PowerShell-файлы.

## Сигналы проблемы

- Файл не декодируется строгим UTF-8 декодером.
- В тексте найдены кодовые точки U+00D0, U+00D1, U+00E2 или U+FFFD.
- После генерации русские заголовки выглядят как набор латинских символов.

## Правило записи файлов

При генерации используйте `System.Text.UTF8Encoding` и пишите файл целиком. Для PowerShell 5.1 это надежнее, чем смешивать разные варианты `Set-Content -Encoding` в разных средах.

## Типовые исправления

- Пересоздайте поврежденный файл из последнего корректного snapshot.
- Не вставляйте кириллицу через терминал, если он показывает неправильную code page.
- После массовой правки сразу запускайте общую проверку.

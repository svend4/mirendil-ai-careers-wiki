# Проверка ссылок

## Назначение

Проверка ссылок нужна, чтобы wiki-структура оставалась навигационной, а не превращалась в набор разрозненных Markdown-файлов. Особенно важно проверять ссылки после массового добавления разделов, переименования папок и пересборки snapshot-генератора.

## Команда

```powershell
.\tools\check-wiki-links.ps1
```

Скрипт проверяет `README.md` в корне и все Markdown-файлы внутри `wiki`.

## Что проверяется

- Относительные локальные пути внутри Markdown-ссылок, например `path/to/file.md`.
- Ссылки из вложенных папок с учетом директории текущего файла.
- Ссылки на Markdown-файлы, PowerShell-скрипты и другие локальные артефакты.

## Что пропускается

- `https://`, `http://`, `mailto:`, `tel:`.
- Чистые якоря вида `#section`.
- Внешние схемы URL.

## Типовые исправления

- Если файл переименован, обновите все ссылки на него через `rg "old-name"`.
- Если новая страница еще не создана, создайте минимальный `README.md` в целевой папке.
- Если ссылка ведет на раздел внутри текущего файла, используйте якорь без имени файла только когда файл не меняется.

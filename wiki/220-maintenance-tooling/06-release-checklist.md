# Release checklist

## Назначение

Release checklist фиксирует минимальный gate перед тем, как считать очередную версию вики готовой к публикации, передаче команде или дальнейшей работе.

## Checklist

- Все новые страницы имеют понятный заголовок первого уровня.
- Все новые разделы добавлены в навигационные индексы.
- Внутренние ссылки проходят проверку.
- Кодировка проходит проверку.
- Snapshot пересобран после добавления новых расширенных разделов.
- Генератор воспроизводит текущую структуру без потери файлов.
- Статистика соответствует ожидаемому росту.
- В новых материалах нет длинного копирования внешних источников: только пересказ, структура и ссылки.
- Риски, gates, scorecards или ownership добавлены там, где материал влияет на эксплуатацию платформы.

## Команда gate

```powershell
.\tools\check-wiki.ps1
```

Для полной проверки воспроизводимости перед gate:

```powershell
.\tools\rebuild-extend-mirendil-wiki.ps1
.\tools\generate-mirendil-wiki.ps1
.\tools\check-wiki.ps1
```

## Что делать при провале

- Сначала исправьте конкретную ошибку, которую вернул скрипт.
- Потом повторите весь gate, а не только упавший шаг.
- Если после генерации исчезли файлы, проверьте список `$includeDirs`.

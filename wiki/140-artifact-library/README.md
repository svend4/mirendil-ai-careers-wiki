# 140-artifact-library

Artifact library содержит рабочие шаблоны документов, которые команда AI R&D платформы заполняет при экспериментах, релизах, инцидентах, security review и операционном планировании.

## Артефакты

- [Experiment brief](01-experiment-brief.md)
- [Eval report](02-eval-report.md)
- [Model release record](03-model-release-record.md)
- [Tool card](04-tool-card.md)
- [Dataset card](05-dataset-card.md)
- [Threat model](06-threat-model.md)
- [Incident report](07-incident-report.md)
- [Compute request](08-compute-request.md)

## Правило использования

Если работа может породить expensive run, model change, new tool, security boundary change или user-facing behavior, у нее должен быть хотя бы один artifact из этого раздела.

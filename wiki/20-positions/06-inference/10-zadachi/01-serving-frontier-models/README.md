# Задание: Построить serving для frontier-моделей

## Цель

Обеспечить высокую пропускную способность и низкую latency для research и product workloads.

## Работы

- Описать workload profiles.
- Выбрать serving framework.
- Добавить autoscaling и request isolation.

## Артефакты

- Serving architecture.
- SLO/SLA profile.
- Load test report.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- GPU underutilization.
- Очереди при agentic bursts.
- Недостаточная изоляция workloads.

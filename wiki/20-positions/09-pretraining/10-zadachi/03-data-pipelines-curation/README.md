# Задание: Построить data pipelines и dataset curation

## Цель

Дать модели качественные, проверяемые и эффективно подаваемые данные.

## Работы

- Собрать ingestion pipeline.
- Добавить filtering, deduplication и quality metrics.
- Проверить влияние data mix на обучение.

## Артефакты

- Data pipeline spec.
- Dataset quality report.
- Data mix experiments.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Data contamination.
- Bias в data mix.
- I/O bottlenecks на training.

# Задание: Настроить continuous regression detection

## Цель

Быстро видеть, когда новая модель или training recipe ухудшает важное поведение.

## Работы

- Запускать eval автоматически.
- Сохранять baseline и diff.
- Настроить алерты по значимым деградациям.

## Артефакты

- CI для eval.
- Regression dashboard.
- Release gate policy.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Слишком шумные алерты.
- Игнорирование rare failures.
- Медленные eval блокируют итерации.

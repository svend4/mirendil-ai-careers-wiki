# Задание: Собрать agent-assisted workflows для инспекции поведения

## Цель

Помочь людям быстрее разбирать outputs, traces и ошибки модели.

## Работы

- Спроектировать интерфейс review.
- Использовать агента для кластеризации failures.
- Собирать structured feedback.

## Артефакты

- Review workflow.
- Failure clusters.
- Feedback dataset.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Агент скрывает важные ошибки.
- Смещение ревьюеров.
- Плохое качество labels.

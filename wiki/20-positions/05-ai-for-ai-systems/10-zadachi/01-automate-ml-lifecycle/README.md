# Задание: Автоматизировать части ML lifecycle

## Цель

Создать агенты и пайплайны, которые ускоряют data curation, training, eval и deployment.

## Работы

- Найти повторяемые операции ML-команд.
- Собрать agent workflows для их автоматизации.
- Ввести контроль качества и rollback.

## Артефакты

- ML lifecycle map.
- Agent workflow specs.
- Метрики ускорения.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Автоматизация неправильного workflow.
- Скрытые ошибки в данных.
- Сложность воспроизведения результатов.

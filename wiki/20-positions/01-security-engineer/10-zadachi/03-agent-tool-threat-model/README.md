# Задание: Смоделировать угрозы для агентных tools и внешних систем

## Цель

Понять, какие действия агент может выполнить через инструменты, API и интеграции.

## Работы

- Составить список tools и полномочий.
- Разделить действия на безопасные, опасные и требующие подтверждения.
- Ввести policy engine для блокировки и human approval.

## Артефакты

- Threat model.
- Политики tool access.
- Таблица approval-gates.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Prompt injection через внешние данные.
- Непреднамеренные операции в production.
- Компрометация секретов через tool output.

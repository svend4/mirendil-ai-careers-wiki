# Задание: Построить безопасный sandbox для AI-generated code

## Цель

Дать агентам возможность запускать код без прямого риска для инфраструктуры и данных.

## Работы

- Выбрать границы изоляции: контейнер, microVM, namespace, network policy.
- Ограничить файловую систему, сеть, секреты, CPU/GPU и время выполнения.
- Добавить журналирование команд, артефактов и внешних запросов.

## Артефакты

- Спецификация sandbox.
- Набор негативных тестов.
- Runbook для расследований.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Escape из sandbox.
- Exfiltration через сеть.
- Скрытое сохранение вредного состояния между запусками.

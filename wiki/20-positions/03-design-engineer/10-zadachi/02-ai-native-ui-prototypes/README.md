# Задание: Собрать AI-native интерфейсы для исследовательских задач

## Цель

Показать, как должен выглядеть продукт, где пользователь работает вместе с моделью и агентами.

## Работы

- Спроектировать режимы совместной работы человек-агент.
- Добавить просмотр решений, логов и результатов.
- Проверить прототипы на реальных сценариях.

## Артефакты

- Интерактивный прототип.
- Компонентная карта.
- UX-критерии качества.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Скрытые действия агента.
- Перегрузка экранов логами.
- Неясная ответственность между человеком и системой.

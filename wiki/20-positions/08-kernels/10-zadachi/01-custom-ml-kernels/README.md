# Задание: Разрабатывать custom ML kernels

## Цель

Ускорять критические операции training и inference через специализированные kernels.

## Работы

- Найти bottleneck operators.
- Реализовать kernel и интеграцию.
- Сравнить correctness и performance с baseline.

## Артефакты

- Kernel implementation note.
- Correctness tests.
- Benchmark report.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Неверная численная точность.
- Сложность поддержки.
- Производительность только на одном shape.

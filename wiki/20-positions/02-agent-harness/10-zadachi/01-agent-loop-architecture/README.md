# Задание: Спроектировать agent loop и слой инструментов

## Цель

Собрать цикл планирования, действия, наблюдения и рефлексии для AI R&D задач.

## Работы

- Описать состояния agent loop.
- Определить tool API, схемы вызовов и ошибки.
- Ввести prompt scaffolding и capability primitives.

## Артефакты

- Диаграмма agent loop.
- Tool contract.
- Набор примеров задач.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Зацикливание агента.
- Непредсказуемые tool calls.
- Потеря контекста между итерациями.

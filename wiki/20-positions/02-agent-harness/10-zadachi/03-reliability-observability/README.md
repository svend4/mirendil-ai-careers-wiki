# Задание: Добавить guardrails, evals и observability

## Цель

Сделать длинные агентные задачи измеримыми, воспроизводимыми и управляемыми.

## Работы

- Логировать планы, действия, наблюдения и решения.
- Добавить regression evals для agent behavior.
- Описать failure modes и recovery policies.

## Артефакты

- Dashboard поведения агента.
- Набор evals.
- Failure taxonomy.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Тихая деградация качества.
- Ложное ощущение автономности.
- Сложность объяснения решений агента.

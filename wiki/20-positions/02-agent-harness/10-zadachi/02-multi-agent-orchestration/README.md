# Задание: Оркестрировать память, состояние и multi-agent работу

## Цель

Позволить нескольким агентам делить задачу, состояние и результаты экспериментов.

## Работы

- Спроектировать task decomposition.
- Разделить short-term и long-term memory.
- Добавить checkpointing и resume для долгих workflow.

## Артефакты

- Модель состояния.
- Протокол coordination.
- Сценарии восстановления.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Конфликтующие агенты.
- Порча общего состояния.
- Дублирование дорогостоящих GPU-задач.

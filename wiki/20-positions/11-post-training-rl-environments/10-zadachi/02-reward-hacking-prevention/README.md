# Задание: Предотвращать reward hacking

## Цель

Сделать так, чтобы модель не училась обходить метрику вместо решения задачи.

## Работы

- Выявить exploit paths.
- Добавить adversarial tests.
- Сравнить reward с независимыми проверками.

## Артефакты

- Reward threat model.
- Exploit test suite.
- Mitigation plan.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Модель использует баг среды.
- Verifier leakage.
- Награда не отражает реальную полезность.

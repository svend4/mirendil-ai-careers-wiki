# Задание: Автоматизировать сбор данных для long-horizon RL

## Цель

Получать качественные траектории для сложных задач с множеством решений.

## Работы

- Определить environment schema.
- Собирать trajectories, states и outcomes.
- Фильтровать невалидные и низкосигнальные данные.

## Артефакты

- Environment data schema.
- Collection pipeline.
- Data quality report.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Шумные траектории.
- Смещение environment distribution.
- Дорогая генерация данных.

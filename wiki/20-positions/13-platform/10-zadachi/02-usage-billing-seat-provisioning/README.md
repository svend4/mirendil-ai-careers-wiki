# Задание: Построить usage tracking, billing и seat provisioning

## Цель

Сделать использование compute и platform resources измеримым и управляемым.

## Работы

- Определить billable events.
- Связать usage с org, user и agent.
- Добавить лимиты, квоты и уведомления.

## Артефакты

- Usage event catalog.
- Billing integration spec.
- Quota policy.

## Критерии готовности

- Есть владелец результата и понятная граница ответственности.
- Результат проверяется через тест, eval, benchmark, review или audit.
- Риски задокументированы до запуска в production или expensive research run.

## Риски

- Непредсказуемые расходы.
- Неточный attribution.
- Блокировка важных research runs.

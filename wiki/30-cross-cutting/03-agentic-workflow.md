# Сквозная тема: agentic workflow

## Почему это сквозная тема

Автономный AI R&D контур держится на способности агента планировать, действовать, сохранять состояние, пользоваться tools и объяснять решения. Это затрагивает model capability, infra, UX и security одновременно.

## Ключевые вопросы

- Как агент выбирает следующий шаг?
- Какие состояния сохраняются между итерациями?
- Где человек должен вмешиваться?
- Как показать trace пользователю?
- Как измерять надежность long-horizon tasks?

## Минимальные артефакты

- Agent loop diagram.
- Tool contract.
- State model.
- Trace viewer requirements.
- Human approval policy.

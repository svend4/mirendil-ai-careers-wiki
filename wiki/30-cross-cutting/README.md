# 30-cross-cutting

Сквозные темы, которые проходят через несколько позиций. Эти страницы связывают отдельные профессии в единую AI R&D систему.

## Темы

- [Безопасность и sandboxing](01-security-sandboxing.md) - Security Engineer, Infrastructure, Platform, Agent Harness.
- [Evaluation и verifiers](02-evaluation-verifiers.md) - Model Evaluation, Post-Training RL, RL Environments.
- [Agentic workflow](03-agentic-workflow.md) - Agent Harness, Product Development, Design Engineer, AI for AI Systems.
- [Compute efficiency](04-compute-efficiency.md) - Pretraining, Inference, Kernels, Infrastructure.
- [Governance и auditability](05-governance-auditability.md) - Platform, Security Engineer, Product Development.

## Почему это отдельный раздел

Многие реальные проблемы AI R&D не принадлежат одной команде. Например, reward hacking требует работы RL, eval, security и product одновременно.

## Общая логика

| Период | Фокус | Типичный результат |
| --- | --- | --- |
| 0-30 дней | Понять систему, owners, vocabulary и baseline workflows | первый reviewable artifact |
| 31-60 дней | Сделать controlled contribution в одном delivery slice | улучшение workflow, gate, eval, benchmark или policy |
| 61-90 дней | Взять ограниченный ownership area | roadmap, release-ready artifact или measurable improvement |

## Как использовать

- Для onboarding выберите страницу роли и назначьте first artifact.
- Для manager review используйте milestones как evidence-based expectations.
- Для самообучения соединяйте этот раздел с [role practical assignments](../250-role-practical-assignments/README.md).

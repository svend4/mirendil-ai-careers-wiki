## Как использовать

1. Выберите роль и откройте ее практическую страницу.
2. Выполните starter assignment для проверки базового понимания.
3. Выполните core assignment как основной портфельный артефакт.
4. Выполните stretch assignment для senior-level проверки trade-offs, risks и platform thinking.
5. Сравните результат со [scorecards](../65-scorecards/README.md), [hiring kits](../160-hiring-interview-kits/README.md) и [artifact library](../140-artifact-library/README.md).

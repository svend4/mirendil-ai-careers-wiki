## Как читать

1. Начните с [карты системы](10-overview/architecture-map.md).
2. Откройте [индекс позиций](20-positions/README.md).
3. Для обучения выберите [curriculum](100-curriculum/README.md), [first 90 days](260-first-90-days/README.md) или [дорожную карту](40-roadmaps/README.md).
4. Для практики выберите [проект](50-projects/README.md), [capstone lab](270-capstone-labs/README.md), [red-team drill](370-red-team-drills/README.md) или [evidence packet](290-evidence-packets/README.md).
5. Для оценки навыков используйте [scorecards](65-scorecards/README.md), [hiring kits](160-hiring-interview-kits/README.md) и [role practical assignments](250-role-practical-assignments/README.md).
6. Для рабочих процедур используйте [playbooks](70-playbooks/README.md).
7. Для архитектурных решений проверьте [reference architecture](80-reference-architecture/README.md), [protocols](200-protocols-contracts/README.md), [decision trees](330-decision-trees/README.md), [benchmark suite blueprints](430-benchmark-suite-blueprints/README.md), [labeling guidelines](450-labeling-guidelines/README.md), [decision record examples](280-decision-record-examples/README.md) и [quality gates](85-quality-gates/README.md).

9. Для планирования реализации откройте [implementation backlog](110-implementation-backlog/README.md) и [delivery plans](240-delivery-plans/README.md).

Для управления командой откройте [operating model](120-operating-model/README.md), [risk register](130-risk-register/README.md), [governance policies](230-governance-policies/README.md), [dataset recipes](440-dataset-recipes/README.md), [evaluator calibration](460-evaluator-calibration/README.md), [ownership/RACI](350-ownership-raci/README.md), [operational review cadences](310-operational-review-cadences/README.md), [operating reports](380-operating-report-templates/README.md), [control catalog](390-control-catalog/README.md) и [anti-patterns/remediations](300-anti-patterns-remediations/README.md).

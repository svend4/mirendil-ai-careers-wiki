# 130-risk-register

Risk register хранит ключевые риски AI R&D платформы. Его задача - не пугать, а сделать риски управляемыми: owner, indicators, mitigations, gates и review cadence.

## Риски

- [RISK-001: Agent autonomy runaway](RISK-001-agent-autonomy-runaway.md)
- [RISK-002: Evaluation gaming and Goodhart](RISK-002-evaluation-gaming-goodhart.md)
- [RISK-003: Data leakage and lineage gaps](RISK-003-data-leakage-lineage-gaps.md)
- [RISK-004: Sandbox escape and unsafe tools](RISK-004-sandbox-escape-unsafe-tools.md)
- [RISK-005: Compute runaway cost](RISK-005-compute-runaway-cost.md)
- [RISK-006: Model release regression](RISK-006-model-release-regression.md)
- [RISK-007: Product trust failure](RISK-007-product-trust-failure.md)

## Review cadence

- Weekly: active risks and new incidents.
- Monthly: severity, owner и mitigation status.
- Before launch: affected risks must be reviewed.
- After incident: add new indicator or mitigation.

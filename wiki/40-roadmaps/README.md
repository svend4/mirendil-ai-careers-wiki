# 40-roadmaps

Дорожные карты связывают роли Mirendil в учебные и рабочие треки. Их можно читать как планы развития команды, учебные программы или backlog для внутренней AI R&D платформы.

## Треки

- [Agentic AI R&D](01-agentic-ai-rnd.md) - agent harness, tools, sandbox, long-running agents.
- [Post-training, RL и evaluation](02-rl-evaluation.md) - RL recipes, verifiers, reward quality, eval gates.
- [Compute, pretraining и inference](03-compute-training-inference.md) - GPU clusters, kernels, distributed training, serving.
- [Security, platform и governance](04-security-governance.md) - identity, audit, isolation, compliance, model assets.
- [Product и AI-native UX](05-product-ai-native-ux.md) - интерфейсы, workflow, продуктовые абстракции.

## Формат чтения

Каждый трек устроен одинаково: цель, связанные роли, базовые знания, практические задания, артефакты и контрольные вопросы.

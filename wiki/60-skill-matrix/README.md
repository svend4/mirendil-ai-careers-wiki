# 60-skill-matrix

Матрица компетенций помогает увидеть, какие знания повторяются между позициями, а какие являются специализацией отдельной роли.

## Основные кластеры

| Кластер | Роли | Что нужно уметь |
| --- | --- | --- |
| Agent systems | Agent Harness, AI for AI Systems, Product Development | Agent loop, tools, memory, trace, approval gates |
| RL and eval | Post-Training RL, RL Environments, RL Infra, Model Evaluation | Reward design, verifiers, trajectories, regression detection |
| Compute | Pretraining, Inference, Kernels, Infrastructure | GPU scheduling, distributed training, serving, profiling |
| Security and governance | Security Engineer, Platform, Infrastructure | IAM, sandboxing, audit, isolation, compliance |
| Product and UX | Design Engineer, Product Development, Model Evaluation | Workflow mapping, research UI, trace viewer, product metrics |

## Уровни зрелости

### Уровень 1: Понимание терминов

Человек может объяснить основные понятия и связи: agent harness, RL, verifier, sandbox, checkpoint, inference, eval.

### Уровень 2: Проектирование

Человек может описать архитектуру, контракты, риски, артефакты и критерии готовности.

### Уровень 3: Реализация

Человек может собрать минимальный рабочий прототип, добавить observability и проверить failure modes.

### Уровень 4: Масштабирование

Человек может переносить решение на большие данные, GPU clusters, long-running tasks, multi-tenant product и regulated environments.

## Как использовать

- Для обучения: выберите один кластер и пройдите соответствующую дорожную карту.
- Для найма: используйте уровни как основу scorecard.
- Для продукта: проверяйте, закрыты ли все кластеры в roadmap.

## Что оцениваем

Способность превращать AI R&D capabilities в понятные research workflows: experiment dashboard, trace viewer, approval queue, eval comparison и product metrics.

## Уровни

| Уровень | Поведение |
| --- | --- |
| L1 | Объясняет research workflow и основные продуктовые сущности |
| L2 | Проектирует information architecture и UI state model |
| L3 | Собирает prototype, проверяет edge states и собирает feedback |
| L4 | Управляет AI-native product strategy, trust, adoption и metrics |

## Practical exercise

Спроектировать интерфейс review для agent proposal: пользователь видит гипотезу, trace, eval comparison, risk flags и может принять, отклонить или отправить на итерацию.

## Evidence

- Journey map.
- Product entity model.
- Trace viewer design.
- UI state matrix.
- Product metric tree.
- User feedback summary.

## Красные флаги

- UI скрывает действия агента.
- Пользователь видит только финальный ответ без evidence.
- Approval states непонятны.
- Product metrics измеряют activity, а не time-to-insight.
- Internal abstractions без фильтра протащены в продукт.

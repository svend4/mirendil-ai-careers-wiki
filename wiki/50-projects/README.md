# 50-projects

Практические проекты для развития вики и проверки понимания тем. Каждый проект можно превратить в отдельный репозиторий, учебный модуль или внутреннюю инициативу.

## Проекты

- [Мини-платформа AI R&D агента](01-mini-ai-rnd-agent-platform.md)
- [Evaluation и verifier suite](02-eval-verifier-suite.md)
- [Sandbox для AI-generated code](03-secure-code-sandbox.md)
- [Compute и inference observability](04-compute-inference-observability.md)
- [AI-native research dashboard](05-ai-native-research-dashboard.md)

## Как выбирать проект

- Если цель - понять агентность, начните с проекта 01.
- Если цель - безопасность, начните с проекта 03.
- Если цель - ML research quality, начните с проекта 02.
- Если цель - инфраструктура, начните с проекта 04.
- Если цель - продукт и UX, начните с проекта 05.

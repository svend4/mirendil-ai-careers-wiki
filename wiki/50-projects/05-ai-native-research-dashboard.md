# Проект: AI-native research dashboard

## Идея

Спроектировать интерфейс, где исследователь видит гипотезы, runs, checkpoints, evals, agent traces и решения в одном связанном workflow.

## Роли

- Design Engineer
- Product Development
- Model Evaluation
- Agent Harness

## Компоненты

- Experiment list и run detail.
- Timeline решений и артефактов.
- Eval comparison view.
- Agent trace viewer.
- Approval queue для опасных действий.

## Минимальный результат

- Information architecture.
- UI state model.
- 3 ключевых сценария: создать эксперимент, сравнить runs, принять или отклонить agent proposal.

## Расширения

- Inline human feedback.
- Diff между checkpoints и eval profiles.
- Failure clustering.
- Product metrics: time-to-insight и review burden.

# 110-implementation-backlog

Implementation backlog раскладывает AI R&D платформу на эпики. Это не sprint plan, а структурированный список направлений, которые можно постепенно превращать в issues, проекты или milestones.

## Эпики

- [Epic 01: Agent runtime MVP](01-agent-runtime-mvp.md)
- [Epic 02: Evaluation platform MVP](02-evaluation-platform-mvp.md)
- [Epic 03: Secure sandbox and tools](03-secure-sandbox-tools.md)
- [Epic 04: Compute platform foundation](04-compute-platform-foundation.md)
- [Epic 05: Product research workspace](05-product-research-workspace.md)
- [Epic 06: Governance, audit and lineage](06-governance-audit-lineage.md)

## Приоритетная последовательность

1. Governance и sandbox boundaries до автономных запусков.
2. Agent runtime MVP с trace и approval gates.
3. Evaluation platform MVP до любых model promotions.
4. Compute foundation для expensive workloads.
5. Product workspace для review и adoption.
6. Lineage и retention как обязательный слой масштабирования.

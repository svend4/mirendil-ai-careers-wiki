# Maturity levels

## Уровни

| Уровень | Название | Описание |
| --- | --- | --- |
| M0 | Ad hoc research | Эксперименты ручные, trace неполный, ownership неясен |
| M1 | Documented workflows | Есть wiki, artifacts, роли и basic review |
| M2 | Instrumented experiments | Эксперименты имеют trace, budget, eval report и decision records |
| M3 | Governed agent loops | Agent runtime работает с sandbox, approvals, audit и eval gates |
| M4 | Scaled AI R&D platform | Compute, eval, security и product workflows масштабируются по командам |
| M5 | Domain deployment engine | Платформа переносится в domain scenarios с governance и measurable adoption |

## Переходы

- M0 -> M1: ввести docs, roles, artifacts.
- M1 -> M2: ввести trace, eval reports, metrics.
- M2 -> M3: ввести controlled agent runtime и sandbox.
- M3 -> M4: ввести platform operations, capacity planning, risk register.
- M4 -> M5: ввести repeatable domain onboarding и product adoption metrics.

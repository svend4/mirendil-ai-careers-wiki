# Capability assessment

## Цель

Оценить зрелость платформы по capability areas, а не по общему впечатлению.

## Assessment table

| Area | M1 evidence | M3 evidence | M5 evidence |
| --- | --- | --- | --- |
| Agent runtime | Agent loop design | Sandbox + approvals + trace | Multi-domain autonomous workflows |
| Evaluation | Eval catalog | Release gates + regression dashboards | Domain-specific eval factory |
| Compute | Capacity notes | Quotas + cost attribution | Scaled scheduling across teams |
| Security | Threat models | Audit + policy engine + incidents | Compliance-ready governance |
| Product | Workflow maps | Trace review + approval UI | Measured domain adoption |
| Operations | Owners listed | Cadence + decision records | Repeatable launch/change model |

## Scoring

- 0: нет evidence.
- 1: documented only.
- 2: used manually.
- 3: used in active workflows.
- 4: measured and reviewed.
- 5: repeatable across domains.

## Output

- Current maturity level.
- Weakest capability area.
- Top 5 remediation actions.
- Next review date.

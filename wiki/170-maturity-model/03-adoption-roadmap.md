# Adoption roadmap

## Цель

Показать, как постепенно внедрять AI R&D платформу без большого взрыва и без преждевременной автономности.

## Фаза 1: Documentation and artifacts

- Ввести wiki navigation.
- Использовать experiment brief, eval report, tool card.
- Назначить owners.
- Начать decision records.

## Фаза 2: Instrumented workflows

- Добавить trace для experiments.
- Ввести eval reports и baseline comparisons.
- Запустить executive health dashboard.
- Проводить weekly gate review.

## Фаза 3: Controlled agent runtime

- Подключить tool registry.
- Ограничить sandbox.
- Ввести approval gates.
- Включить agent runtime metrics.

## Фаза 4: Platform operations

- Ввести compute capacity planning.
- Поддерживать risk register.
- Запустить incident/escalation model.
- Проверять production readiness.

## Фаза 5: Domain scaling

- Выбрать scenario.
- Добавить domain evals и dataset cards.
- Измерить adoption и time-to-insight.
- Повторить onboarding для следующего domain.
